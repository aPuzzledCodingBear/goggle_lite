# Measurement record template

Create a dated Markdown record for each test and attach raw logs/photos. Do not prefill pass results here.

- Date, operator, ambient temperature/light:
- Zero/CCPA/OL23 hardware and firmware versions:
- OS image, kernel, FastCarPlay commit, configuration:
- Module boundaries, connectors, wiring, cable length, supply, input timings:
- Test steps, sample count, expectations:
